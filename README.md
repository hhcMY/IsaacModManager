# 以撒 Mod 管理器

在游戏外面管理《以撒的结合》的 mod：批量开关、改 mod 在游戏里显示的名字。
不用进游戏，也不动 `disable.it` 之外的东西。

纯 PowerShell + .NET WinForms 写的，**Win10 / Win11 自带运行环境，不用装任何东西**，也不需要管理员权限。

## 能干什么

- 列出 `mods` 文件夹里所有 mod，勾选框直接开关
- 改显示名称（写 `metadata.xml` 里的 `<name>`，保留文件原编码，GBK 老 mod 也不会乱码）
- 按名字 / 文件夹名搜索，mod 多了好找
- 显示版本号
- 自动识别游戏目录（注册表 → Steam 库 → 常见盘符），也可以手动选
- 一键打开 `mods` 文件夹
- 和战报工具共用同一个 `config.json`，改一处两边都生效

## 快速开始

1. 下载 / 克隆到本地任意文件夹
2. 双击 `Mod管理器.vbs`
3. 第一次会弹「设置路径」：点「自动识别游戏目录」，不行就「浏览」选到
   `...\steamapps\common\The Binding of Isaac Rebirth`
4. 勾选或改名 → 点「保存」→ 重启游戏

> 从网上下载的压缩包请先右键 → 属性 → 勾「解除锁定」，再解压，否则脚本可能被拦。

## 文件

| 文件 | 作用 |
| --- | --- |
| `Mod管理器.vbs` | 启动器，不弹黑框，启动失败会弹提示 |
| `mod-manager.ps1` | 主程序（界面 + 读写 mod） |
| `common.ps1` | 配置读写、自动找游戏目录 |
| `config.json` | 路径配置，首次运行自动生成（已在 `.gitignore` 里） |
| `说明.txt` | 给玩家看的详细说明 |

## 它改了什么

| 操作 | 实际动作 |
| --- | --- |
| 启用 / 禁用 | 在 mod 目录新建 / 删除空文件 `disable.it` |
| 改显示名 | 改写 `metadata.xml` 的 `<name>`，保持原文件编码 |
| 改路径 | 写 `config.json` |

不改注册表、不装服务、不联网、不碰存档。卸载就是删文件夹。

## 常见问题

**双击没反应 / 提示「Windows 已保护你的电脑」**
右键压缩包 → 属性 → 勾「解除锁定」→ 确定，重新解压。

**提示「无法加载文件，因为在此系统上禁止运行脚本」**
不是通过 `Mod管理器.vbs` 启动的。用 vbs 双击，或右键 `mod-manager.ps1` → 使用 PowerShell 运行。

**一个 mod 都列不出来**
游戏目录填错了，点「设置路径」重选；确认目录下有 `mods` 文件夹。

**改名 / 开关不生效**
需要重启游戏。

**能传到创意工坊吗**
不能。工坊只收游戏内 mod（Lua），这是 Windows 桌面程序。
