Mod 管理器 v1.1 —— 使用说明
================================

作用：不进游戏，直接在外面开关以撒的 mod、改 mod 在游戏里显示的名字。
      纯 PowerShell 写的，Win10 / Win11 自带运行环境，不用装任何东西。


一、第一次用（4 步）
--------------------

  1. 把压缩包解压到一个文件夹里（别直接在压缩包里双击运行）

  2. 双击「Mod管理器.vbs」

  3. 会弹出「设置路径」窗口，点「自动识别游戏目录」；
     认不出来就点「浏览」，选到含 isaac-ng.exe 的文件夹：
       ...\steamapps\common\The Binding of Isaac Rebirth
     不知道在哪：Steam → 库 → 右键 The Binding of Isaac → 管理 → 浏览本地文件

  4. 点「保存并刷新」，窗口里出现 mod 列表就成了


二、界面
--------

  启用       打勾 = 这个 mod 开着
  显示名称   游戏里看到的名字，双击（或按 F2）可以改
  版本       从 mod 的 metadata.xml 读出来的，只读
  文件夹     mod 的实际目录名，只读，别改
  搜索       按名字或文件夹名过滤，清空就显示全部

  按钮：
    保存             把改动写进 mod 文件夹
    全部启用 / 禁用   只作用于「当前看得见的」行（有搜索词时注意）
    刷新             重新读一遍 mod 文件夹
    设置路径         改游戏目录 / 卡片输出目录
    打开 mods 文件夹  直接用资源管理器打开

  ★ 勾选或改名之后必须点「保存」，然后重启游戏才生效。


三、它在背后改了什么
--------------------

  启用 / 禁用：在 mod 文件夹里 新建 / 删除 一个空的 disable.it
  改显示名：   改 metadata.xml 里的 <name> 标签
               （会保留文件原来的编码，GBK 的老 mod 也不会变乱码）
  改路径：     写同目录的 config.json

  不改注册表、不装服务、不联网、不碰存档。
  卸载 = 把这个文件夹删掉。


四、注意
--------

  1. 不要改「文件夹」那一列，游戏靠文件夹名找 mod

  2. 没有 metadata.xml 的 mod 改不了名（列表里显示文件夹名）

  3. 一个 mod 都列不出来 = 游戏目录填错了，点「设置路径」重选

  4. 创意工坊的 mod 订阅更新后，名字可能被改回原样，重改一次就行

 

五、打不开 / 报错
-----------------

  1. 双击 vbs 没反应，或者提示「Windows 已保护你的电脑」：
     右键压缩包 → 属性 → 勾「解除锁定」→ 确定，然后重新解压一次

  2. 提示「无法加载文件，因为在此系统上禁止运行脚本」：
     说明不是用 vbs 启动的。改用双击 Mod管理器.vbs，
     或右键 mod-manager.ps1 → 使用 PowerShell 运行

  3. 想看具体报错：右键 mod-manager.ps1 → 使用 PowerShell 运行（会留个窗口）

  4. 双击后弹「启动失败」：多半是杀毒软件拦了，把整个文件夹加白名单再试


六、文件说明
------------

  Mod管理器.vbs     启动器（不弹黑框，启动失败会弹提示）
  mod-manager.ps1   主程序（界面）
  common.ps1        配置读写 + 自动找游戏目录
  config.json       路径配置（和战报工具共用同一个文件）
  说明.txt          本文件
  README.md         GitHub 上显示的项目说明，本地可以不管


七、和战报工具的关系
--------------------

  两边用同一个 config.json：在这里改了路径，战报工具下次运行就用新路径；
  反过来也一样。改一处，两边都生效。
